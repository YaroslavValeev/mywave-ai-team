Orchestration/runtime/context/execution/GitHub/QA/UX/security/KPI остаются
техническими функциями существующего контура. Они не получают права Федерации
из-за названия роли. Knowledge Intake — точка подготовки draft с источниками,
а knowledge — scoped retrieval и курирование после review.

В каждой будущей записи registry обязательны: id, version, implementation_ref,
allowed_workspaces/projects, read/write scopes, supported_action_types,
authority requirements, output schema, enabled=false по умолчанию.
Отсутствующий обработчик даёт NEED_INFO/unsupported, а не подменяется generic
стратегическим отчётом. Executive агрегирует только результаты, разрешённые
текущему владельцу/получателю, и прикладывает ссылки на исходные карточки.
