# Playbook: cross-layer effectiveness

## Как читать synthesis

- **Slices** — по каждому слою (tuning, collaboration): сколько effective / ineffective / follow-up.
- **Alignment items** — рассогласования: collaboration улучшил, tuning ухудшил; оба требуют follow-up.

## Когда смотреть

- После нескольких tuning patch и collaboration execution — общая картина.
- При ощущении «одно улучшилось, другое просело» — synthesis покажет конфликт.

## Что делать при конфликте

- Открыть `/owner/tuning/outcomes` и `/owner/collaboration/outcomes` по evidence_refs.
- Пересмотреть порядок интервенций (сначала tuning или collaboration).
