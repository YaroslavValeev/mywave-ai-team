# Playbook: decision bundle

## Как читать bundle

- **headline** — суть.
- **why_now** — зачем сейчас.
- **top_problem** — главная проблема.
- **do_now / do_next / defer** — порядок действий.

## bundle_type — что значит

- **project_intervention_bundle** — фокус на проекте.
- **portfolio_attention_bundle** — общий портфель.
- **collaboration_resolution_bundle** — collaboration bottleneck.
- **tuning_recovery_bundle** — tuning lane.
- **cross_layer_conflict_bundle** — конфликт слоёв.

## related_objects

Ссылки на execution_id, tuning_candidate_id, task_id — для навигации в UI/API.
